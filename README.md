## O que eu faço

**Como AI Implementation Specialist na Carmillion**
Cuido de uma carteira de 20 clientes, revendas de veículos que usam um agente de IA para atender no WhatsApp. Meu trabalho vai da conversa com o cliente até o agente funcionando:

- **Entender o negócio:** levanto como cada revenda atende, vende e financia, e transformo isso em regras para o agente.
- **Configurar o agente:** engenharia de prompts, dados que o agente precisa coletar, formas de pagamento, quando ele passa a conversa para uma pessoa.
- **Integrar:** conecto a plataforma ao Mercado Livre, OLX e Webmotors (leads e estoque) e mexo no banco de dados do cliente.
- **Manter o CRM:** parametrização, funcionalidades no front-end e desenvolvimento em Python e Spring Boot.
- **Resultado:** o agente responde 100% das mensagens, atende todo o omnichannel da Meta e fala só com cliente qualificado.

**Como desenvolvedor Full Stack (freelancer)**
Mantenho e evoluo um sistema empresarial em produção (React, Node.js, TypeScript, PostgreSQL): tirei consultas N+1 de listagens operacionais, criei relatórios de produção em tempo real e exportação para Excel e PDF.
